# 管理台使用说明

更新：2026-10-30。管理台使用统一的桌面侧栏和手机抽屉导航，功能按工作空间、自动运行、记录与维护分组。页面刷新即可读取新版界面，不需要为本次前端重排重启收发程序。

| 页面 | 用来做什么 |
|---|---|
| 工作台 | 当前智能体、处理队列、抖音/QQ/鲸聊连接与九模块运行监测 |
| 连接与账号 | 分别检查抖音、QQ和鲸聊；维护登录、配对设备与主动消息目的通道 |
| 智能体与会话 | 查看当前主体和会话，选择Codex/DSH/AstrBot后明确应用；查看列表不会切换 |
| 能力与工具 | AstrBot语音、生图、音乐插件状态和配置入口；电脑可打开独立手动生图 |
| 群聊回复 | 只配置允许自动回复的抖音群及成员，不更改真实群角色 |
| 自动活动 | 保存推荐选片时段和额度；查看日记插件主动联系的巡检/发送记录 |
| 消息记录 | 在回复/发送记录和接收/处理任务间切换，按通道查看文字、图片、语音和作品卡 |
| 作品评论 | 评论开关、@主人、每日额度、主站登录检查与发布记录集中维护 |
| 资源与发送 | 私信发送开关/间隔，资源目录、保留周期和清理预览 |
| 诊断与维护 | 电脑端查看日志及展开程序启动/停止/退出操作 |

## 常用操作

- 想改谁回复：智能体与会话。想改主动消息发到哪里：连接与账号。普通消息仍固定回复原通道和原设备。
- QQ掉线：连接与账号→QQ，可分辨维护程序、QQ登录与OneBot收发接口。手机仅只读检查，扫码和启动在电脑上操作。
- 手机暂时断线：先重试连接。聊天正常但管理页异常时点右上角刷新；加载失败可单独打开管理台，不必重新配对。
- 自动选片改动后点“保存选片设置”。日记主动联系的频率、人设与插件设置仍由AstrBot原页面管理。
- 资源清理只在明确保存规则或确认预览后执行；浏览本页不会清理文件。手机可查看路径，不能修改资源目录或执行清理。
- 关闭管理台网页不会退出程序；诊断与维护中的“关闭整个程序”会同时关闭鲸聊网关。

## 页面交互

桌面侧栏按职责分组；手机左上角按钮打开导航，选中后自动关闭。设置、群聊、评论和活动页面的未保存编辑在离开或刷新前提示，避免定时刷新覆盖输入。连接/设备与会话选择页面不定时重建，防止选择到一半被刷新重置。工作台与记录页按需更新状态；查看依据时保留结果不明的事实，不将平台接受当成手机已收到。

本次重排保留原API、权限与保存参数，不改变人设、模型、登录、配对、消息历史或已保存的额度/时段。私信仍纯文字5秒、含媒体10秒静默等待。AstrBot语音和本地生图的专属许可不变。

## 固定会话选择

Codex 固定读取 部署配置 `codex_workspace` 对应项目中的现存、未归档会话，显示应用中保存的真实标题；不再提供自动跟随、候选范围或备用会话。切换时必须选择具体会话并点击应用。没有已保存的有效会话编号时，新任务留队，不猜测投递目标。

DSH 读取宿主的现存会话，并用 `workspaceRegistry.archivedSessionIds` 排除归档，子智能体与需要迁移的记录同样不列出。归档后的会话不能再被新选中或投递；当前选择失效时重新选择，不改投其他会话。

AstrBot 保留新建会话按钮；创建后还须明确选择和应用。Codex/DSH 暂不增加跨应用创建入口：请先在相应应用中创建，再刷新列表选择，避免创建未正确登记到原应用的新会话。三种主体不改变资源目录。

以上后端和 DSH 连接器修改需正常重启相应程序后加载；仅刷新页面不代表后端生效。

## 异常维护

工作台“会话投递与分析”和“私信回复发送”卡片新增“维护”，也可从消息记录进入“异常维护”。这是可选的人工收尾入口，日常自动检查和收发继续运行，不需要逐条核验。

- **结束并忽略**：用于卡住的待投递、处理或媒体准备任务。记录人工结束，释放处理位置，取消本轮尚未发送的回复和未发布评论；迟到的模型完成提交会被拒绝。不会强制终止宿主模型，也不会撤回已发送的内容。
- **取消本轮待发送回复**：取消同一轮所有尚未发送的分段；已经尝试的消息保留原状态。
- **结束超时尝试**：仅允许有明确尝试记录且超过5分钟未结束的发送，结束为结果不明；缺少记录的发送由自动恢复机制观察处理。不会补发。
- **已收到 / 未收到 / 结束关注**：登记主人反馈或保留未知并结束关注，原始回执和发送状态不变。已处理历史不再撑着需关注提示；如果记录状态后来改变则重新检查。
- **批量结束结果不明记录的关注**：只处理当前列表中的结果不明记录，不修改待发送或正在发送的消息，不把它们标成发送成功。

每次操作先确认、再核对最新状态，状态已经变化则拒绝旧操作。操作记录保存在业务数据库的 `queue_maintenance` 表，可在页面查看近期记录。手机管理仅允许已配对且开放管理的设备访问同一受限入口。离线或登录异常仍须维护真实连接，不能靠人工标记改成在线。

更新后正常重启管理台及托管鲸聊网关加载，不需重启AstrBot；DSH归档过滤需另外正常重启DSH。不会自动处理现有异常记录。工作台评论卡片在关闭或异常等状态下均进入“作品评论”，不再误跳“资源与发送”。
