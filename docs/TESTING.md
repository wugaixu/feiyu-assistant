# 验收、故障与发布检查

## 不碰真实账户的检查

所有测试应在 `configure.py` 生成的**独立测试运行目录**执行，不在生产工作流里伪造主人消息。运行目录先创建tests子目录；脚本默认配置会创建它。

```powershell
python deploy/doctor.py --runtime-dir D:\FeiyuData
cd D:\FeiyuData\installed\0.1.0
python -m unittest discover -q
node --test test_whale_bridge.mjs test_whale_standalone.mjs test_whale_pairing.mjs test_whale_upload.mjs
node test_console_ui.cjs
node test_whale_audio_ui.cjs
node test_whale_voice_order.cjs
```

用安装核心依赖的同一Python执行测试。Doctor只检查文件/依赖是否存在，不访问平台、不合成、不假称登录成功。Node网关测试用临时端口、禁用公网隧道，上传桥接使用隔离服务。不要将测试配置指向真实收件队列。

## 人工逐段验收

| 阶段 | 操作 | 通过条件 |
|---|---|---|
| AI本体 | 在所选AI里正常发一句话 | 该会话可回复且有文件/桥接权限 |
| 鲸聊文字 | 真手机给自己的助手发一条唯一文字 | 一条任务、一次分析、回复回原设备 |
| 图片上传 | ＋选一张普通JPG/PNG，随后补一句问题 | 资料包有真实图片；能描述具体内容 |
| 文件上传 | 上传自己创建的短TXT或DOCX | 原件保存、提取正文、失败如实说明 |
| 手机语音 | 连续录两条，中间夹文字，再重新打开 | 旧语音不追加、不换边、不复活；转写对应原条目 |
| Bot语音 | 请AI说一句短话 | 真音频可播放，“查看文字”展开实际合成原文 |
| 分享作品 | 主账号分享一个有权限下载的视频/图集 | DouK文件解码通过，采样/转写/评论进入资料包 |
| 公开评论 | 显式启用后分享一个适合测试的作品 | 账号/作品匹配，实际评论可见，@另行确认 |
| 自主活动 | 设置低次数且明确时段 | 仅配置范围触发，未回复暂停生效，私信回正确设备 |
| 生命周期 | 正常托盘退出再打开 | 无可见控制台，配置/配对/历史保留，服务恢复 |

这类外部端到端测试依赖你自己的账号、手机、网络和模型，不能用HTTP200或本地队列done代替。平台接受仅表明提交已确认；`outcome_uncertain`不能直接再次发送。

## 常见故障

- **管理台在线但不分析**：核对所选主体和会话；检查投递日志、模型额度、DSH连接8794或AstrBot本地Key。不要改投历史已开始任务。
- **抖音收不到但鲸聊正常**：检查SDK实际账号UID/在线、主人身份、外发队列回执；SDK登录、DouK Cookie和主站浏览器是三个独立状态。
- **只安装语音插件却没声音**：9880不在线、权重/参考/依赖不全是常见原因；先本机试听再启用工具，冷启动可能几十秒。
- **图发不出/文件只显示名字**：检查真实附件是否入库、PIL格式/像素/大小、是否所选模型支持图片；未知文件不自动解析，不能只凭文件名回答内容。
- **语音挪到末尾**：服务升级后重新打开手机聊天页。状态轮询只更新已渲染语音，历史按messageId映射；不要把全量voices列表当新消息列表。
- **视频“下载失败”却有文件**：校验manifest、实际解码、图集数量和partial状态；不要临时伪造video_card绕过评论闸门。
- **图生得很慢**：首轮加载、GPU/内存和模型体积会影响耗时；按需/空闲退出节约资源，但下一轮需冷启动。
- **升级后黑色终端**：用隐藏启动入口；检查AstrBot重启进程标志，不强行关闭持有服务的控制台。

## 发布清单

只发布源码、示例、许可和明确的APK资产。检查API Key、Cookie、用户名私聊、设备令牌、数据库、模型、浏览器profile、签名私钥、临时截图和真人头像；它们不应在仓库/ZIP里。不要把 `deployment.local.json` 或运行目录一起压缩。

保留原依赖许可；记录版本与文件SHA256。每次发布均跑语音顺序、文件上传、跨设备鉴权和队列幂等回归，不能仅用Python语法通过代替行为测试。
