# 本地生图适配器

由管理台维护 ComfyUI 生命周期和 SQLite 任务，插件只向已领取的主人私聊提交一批1–10张图片（每轮只提交一次）。
安装本目录到 AstrBot；`app/local_images.py` 为任务与传输实现。
后台任务/公开评论没有一次性许可，不能使用本工具。生成提交结果不明不重试。
不从模型接受服务地址、文件路径、收件人或 Shell 指令。

参考 DSH Qwen Paint 的本地 ComfyUI 路线，以及 toyhank/qwen-image-2.1-8gb 的量化模型组合。
ComfyUI 和模型分别保留原许可证；本目录仅包含本地适配代码，不包含模型权重。

同一描述多张：prompt + count；不同画面：prompts列表，可用prompt指定共同风格。每张独立记录，串行生成、依次入队，失败不重生成，也不取消后续图片。队列最多3批未完成任务。
