# 手动本地生图（文字与多图参考）

## 当前入口（2026-10-25更新，覆盖下方旧应用模式说明）

桌面双击“本地千问生图”，或运行项目`本地生图.vbs`。页面为`http://127.0.0.1:8189/`，管理台“手动生图”也指向这里。已打开的管理台刷新后更新链接；旧`?feiyu_manual=1`入口刷新会跳转新页面。

- 不上传图片：纯文字生图；上传1–16张：Qwen Image 2.1原生参考图生成。可拖入/多选、预览、排序和移除，提示词用“图1”“图2”指定用途。建议先用1–3张，避免显存压力。
- 复用现有GGUF模型、量化文本编码器、VAE、ComfyUI队列。参考图接入`TextEncodeQwenImage21`的`images.image_N`动态接口；采样器连接编码节点的第3个输出（原生64通道latent），尺寸匹配首图比例。无参考图时输出正方形。
- 可选512/768/1024分辨率、1–60步、固定或随机种子；默认768、8步。
- 手动成品正式保存位置为`__IMAGE_OUTPUT__\qwen-日期时间-任务ID-序号.png`。后端使用PreviewImage，中间图在现有运行目录内的ComfyUI/temp；门户后台读取/view并写入目标目录。不会移动历史图片或改变机器人图片路径。
- 独立隐藏门户`app.manual_portal`只监听127.0.0.1:8189，不公开到公网。页面关闭后继续监控和保存已提交的任务；状态持久化在运行目录`manual-images/jobs.json`，恢复只查询历史、不重提交。提交结果不明时明确提示检查队列。
- 页面POST使用每次启动随机令牌和Host校验；图片读取只允许门户记录的正式输出文件。上传经本机ComfyUI原有上传接口保存到input/manual-portal，模型参考图均为用户主动上传的文件。
- 管理台、收信SDK与现有ComfyUI均无需重启。桌面启动器会确保后端和门户在线；无开机自启。手动图不会进入私信出站队列。
- 本次备份：`__RUNTIME_ROOT__\backups\manual-reference-20261025`。回归日志：运行目录`manual-reference-tests.log`。

## 实现与边界

- 使用现有 ComfyUI frontend 1.57.1 自带 App Mode，非自制替代前端、无额外前端服务或新模型。
- `app/manual_images.py` 生成与已验证机器人工作流相同的 API 图，安装独立、显式 URL 才启用的前端扩展。扩展待画布挂载后加载图，并使用官方应用模式命令显示提示词、种子、步数、输出。
- 原有 Python/模型/显卡参数保持：Qwen-Image 2.1 Q4_K、768×768、8步、单张显存批量；手动图和聊天任务共用 ComfyUI 执行队列。
- 不创建主人任务/生图许可，不触及消息数据库、出站队列，不自动发送手动生成的图片。
- 隐藏的正式手动启动器拥有自己启动的后端；已存在的后端只复用。关闭网页不退出后端；手动启动的独立实例不因管理台关闭而被误杀。管理台自己启动的实例仍按原管理台生命周期退出。
- 本机回环监听、不增加公网端口。重装/升级 ComfyUI 前端后，桌面入口会重新安装这一独立扩展；不改厂商原文件。
- 启动日志在运行目录 `tools/local-image/comfyui.log`，失败提示指向同目录 `manual-launch-error.txt`。
