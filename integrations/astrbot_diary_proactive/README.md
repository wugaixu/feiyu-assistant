# 情绪日记主动消息接入

`astrbot_plugin_denia_diary` 保留巡检、触发器、日记素材、免打扰、每日额度、最小间隔与心情暗号。适配层只限制目标为管理台选定的 AstrBot 主人私聊，并将插件决策交给本地统一队列；不修改 AstrBot 核心，不引入第二套主动联系决策模型。

## 安装与升级

先安装情绪日记插件，并在其页面设置主动消息。源码和运行路径继续使用项目配置。

使用本机 Python 执行本目录 `install.py`，它给已安装插件的 main.py / core/proactive/api.py 贴受检补丁，并复制 bridge.py 为 workflow_bridge.py。修改前备份这两个文件；安装脚本只写文件，不重载、不重启。市场更新可能覆盖补丁，更新后需重新检查并应用补丁、重载插件。版本变化导致匹配失败时不要绕过检查。

加载需经主人安排正常重启管理台并重载“情绪日记”插件。初始化只登记就绪状态，不为验收强制触发真实消息。首次巡检按插件自己的时间表运行。

## 流程

```mermaid
flowchart LR
    A[日记插件巡检与触发器] --> B[插件原有闸门与额度]
    B --> C[筛选当前AstrBot会话]
    C --> D[diary_proactive_jobs持久登记]
    D --> E[共用AstrBot单任务worker]
    E --> F[主会话生成一次最终回复]
    F --> G[reply_batch / reply_outbox]
    G --> H[抖音或鲸聊固定目标]
    H --> I[平台提交结果回写插件]
```

暗号不调用模型。普通主动联系只调用一次现有 AstrBot 会话，沿用模型、人设与原生上下文。插件生成的完整日记素材随本轮提供；主动轮不冒充主人新消息，不增加互动计数或识别成主人早晚安。移除本轮直接发送工具，附件仍经过公共校验和唯一队列。

鲸聊主动轮可取得专用语音许可，沿用 GPT-SoVITS、真实附件与原文展开；抖音不发原生语音。本地生图仍只在主人真实新私聊授权下开放，不借主动任务扩大读取文件或生图权限。

插件频率、额度和免打扰只在插件配置维护，管理台显示最近巡检、触发类型及队列结果，手机端只读同一页面。Codex/DSH 不主动联系。切换主体或 AstrBot 会话会改变发送代次，未发送任务取消，即使马上切回也不补发。通道入队时快照固定，普通聊天回复路由不变。

任务5分钟过期；失败、过期、进程中断和结果不明不恢复重试。插件额度按其原有决策时机扣除；只有所有分段得到平台接受回执才回写互动轨迹，并明确不等于手机实际收到。回写前先登记尝试，崩溃时不重复写日志。旧 autonomy 主动任务只退役、过期未发送分段，原历史保留；刷视频选片继续运行。

## 离线验证

- 项目 unittest：`test_diary_proactive`、`test_autonomy`，以及完整回归。
- 管理台：`node test_console_ui.cjs`。
- 插件原93项主动逻辑测试在隔离补丁副本、AstrBot Python环境运行。
- 本目录 `test_plugin_scope.py` 另验证目标筛选、暗号范围、平台回执回写及直发工具移除。设置 `DIARY_PLUGIN_TEST_ROOT` 为隔离插件副本、`DIARY_TEST_TMP` 和 `ASTRBOT_ROOT` 为配置的工作临时目录，避免测试初始化真实 AstrBot 数据。

所有测试使用隔离数据库/文件和模型桩，不对外试发、不修改真实日记或插件频率。
# 主人身份、正文和群聊适配（2026-10-28）

插件的`scope.mode=owner`依赖`love_peers`名单；这里必须使用AstrBot实际发送者标识（本工作流为连接器username），不能填抖音UID/QQ号代替。名单为空时，主人会被判范围外，主动巡检没有目标，普通互动注入及日记/小本本/状态等写工具也会受限。修复通过插件自己的settings扩展接口热保存，仅补入已核验身份，保留其他设置；不改成全私聊开放。

共用`app.diary_context`从本轮有效素材许可和已领取任务读取实际来源。它核验任务、有效期、处理状态、AstrBot会话绑定后，才把任务中的真实文字交给早晚安识别和强提示逻辑；不把JSON信封/路径当用户正文。群任务映射为真实群与发言人的Session，不能借WebChat的主人ID取得私聊日记权限。工作流信封缺失或使用无效许可时按范围外处理；普通原生WebChat保持原行为。主动联系轮继续跳过伪造互动计数。

`install.py`补丁可重复应用，兼容已安装旧版主动桥接标记；更新市场插件后重新贴补丁并核验。配置热生效和代码插件重载是不同步骤，源码写盘不代表已加载。测试覆盖真实文字/语音问候、群身份、失效许可、跨会话、原生聊天以及原有主动触发与队列状态；不强制写生产日记或发送测试消息。
